🎯 KEY FEATURES

✅ Three Review Modes
   ├─ Manual: /review command only
   ├─ Semi-Auto: Auto-review + admin approval
   └─ Auto: Auto-review + auto-merge (confidence >= 0.9)

✅ Universal Platform Support
   ├─ GitHub (GitHub Actions)
   ├─ GitLab (GitLab CI)
   └─ Self-hosted (manual mode)

✅ 100% Automated Installation
   ├─ Auto-detect Git settings
   ├─ Auto-detect platform from remote URL
   ├─ Interactive mode selection
   └─ No manual file editing required

✅ AI Review Engine
   ├─ Security vulnerability detection
   ├─ Performance issue identification
   ├─ Best practices validation
   ├─ Test coverage analysis
   ├─ Documentation completeness
   └─ Error handling patterns

✅ Fallback Support
   ├─ Rule-based analysis (no API required)
   └─ Graceful degradation

🚀 USAGE

Local Development (Manual Mode):
  /review                    # Review current changes
  /review path/to/file.py    # Review specific file
  /review --json             # JSON output

Team Collaboration (Semi-Auto Mode):
  git push origin feature    # Create PR/MR
  # AI automatically reviews and posts comment
  # Admin approves or requests changes

Fully Automated (Auto Mode):
  git push origin feature    # Create PR/MR
  # AI reviews and auto-merges if confidence >= 0.9

⚙️ CONFIGURATION

.claude/config/team.yaml:
  ai_reviewer:
    enabled: true
    mode: "semi-auto"        # manual | semi-auto | auto
    model: "gpt-4"
    auto_merge_threshold: 0.9
    checks:
      - security
      - performance
      - best_practices
      - test_coverage
      - documentation
      - error_handling
    no_auto_merge:
      paths: ["prod/*", ".env*"]
      keywords: ["TODO", "HACK", "FIXME"]
