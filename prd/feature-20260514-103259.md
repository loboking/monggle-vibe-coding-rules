## 1. 배경

### 1.1 현재 문제점

| 문제 | 현상 | 영향 |
|------|------|------|
| **스킬 등록 실패** | `.md` 파일이 전역으로 복사 안됨 | Claude Code가 스킬을 인식 못함 |
| **명령어 혼동** | `/run` vs `/monggle-run` vs `@agent-run` | 사용자가 무엇을 써야 할지 모름 |
| **오타 처리 부족** | `/qaa`가 `/qa`로 자동 교정 안됨 | 매번 정확한 스펠링 필요 |
| **도움말 부족** | 각 스킬 `--help`가 너무 김 | 빠른 참조가 어려움 |
| **설치 후 재시작** | 스킬 설치 후 터미널 재시작 필요 | 즉시 사용 불가 |

### 1.2 사용자 피드백

> "monggle를 처음부터 작성해야 하니 너무 피로감이 들어"
> "스킬이 정상적으로 클로드코드에 등록이 안되는 현상"

---

## 2. 목표 (Goal)

**설치 후 즉시 사용 가능한 스킬 시스템 구축**

1. 스킬 설치 후 재시작 없이 즉시 사용 가능
2. 오타 자동 교정으로 사용자 부하 감소
3. 직관적인 도움말 시스템
4. 일관된 명령어 체계

---

## 3. 기능 요구사항

### 3.1 핵심 기능

#### F1. 스킬 즉시 사용 (Zero-Config Installation)

```bash
# 설치 후 즉시 사용 가능
./install.sh
# → 재시작 없이 바로 스킬 사용 가능
```

**구현 방법:**
- `.md` 파일 전역 복사 (완료)
- 자동완성 스크립트 자동 로드
- `source ~/.zshrc` 자동 실행

#### F2. 오타 자동 교정 (Smart Autocorrect)

```bash
/qaa          → /qa
/debugg       → /debug
/monggl-run   → /monggle-run
/log          → /changelog
```

**구현 방법:**
- `wrapper.sh`에 Levenshtein 거리 기반 교정
- 1-2글자 오차 허용
- 자동 실행 후 알림

#### F3. 대화형 도움말 (Interactive Help)

```bash
/help                    # 카테고리별 목록
/help debug             # 디버그 스킬만
/help --search "test"   # 검색
```

**구현 방법:**
- `/help` 스킬 생성
- 카테고리별 그룹핑
- 퍼지 검색

#### F4. 명령어 체계 문서화

```bash
# 통합 규칙
/{name}        # 짧은 형식
/monggle-{name} # 긴 형식 (동일)
@agent-{name}  # 백그라운드
```

**구현 방법:**
- 모든 스크립트에 monggle 접두사 (완료)
- 문서에 규칙 명시
- 예시 통일

### 3.2 업그레이드 시스템

#### F5. 자동 업그레이드 체크

```bash
# 스킬 실행 시 자동 체크 (24시간 쓰로틀)
/qa
# → 업그레이드 있으면 알림
```

**구현 방법:**
- `skill-harness-wrapper.sh` (이미 구현됨)
- `UPGRADE_CHECK=false`로 비활성화

#### F6. 수동 업그레이드

```bash
/monggle-upgrade          # 확인 및 설치
/monggle-upgrade --force  # 강제 체크
```

**구현 방법:**
- GitHub API 사용 (이미 구현됨)
- git fetch fallback

## 4. 기술 사양

### 4.1 파일 구조

```
~/.claude/commands/
├── wrapper.sh           # 오타 교정 래퍼 (신규)
├── help.sh              # 대화형 도움말 (신규)
├── *.sh                 # 스크립트 (monggle 접두사)
└── *.md                 # 스킬 메타데이터 (전역 복사)
```

### 4.2 수정 파일

| 파일 | 변경 사항 |
|------|----------|
| `install.sh` | .md 파일 전역 복사 로직 추가 |
| `wrapper.sh` | 오타 교정 래퍼 신규 생성 |
| `help.sh` | 대화형 도움말 신규 생성 |
| `monggle-upgrade.sh` | GitHub API 최적화 |
| `skill-harness-wrapper.sh` | 자동 업그레이드 체크 |

### 4.3 의존성

```bash
# 필요 없음 (순수 Bash)
```
