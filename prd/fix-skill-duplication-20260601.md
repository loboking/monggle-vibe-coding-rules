# PRD: 글로벌 스킬 중복 노출 정리

> **타입:** bug
> **작성일:** 2026-06-01
> **상태:** 구현 진행

---

## 1. 문제 정의

글로벌(`~/.claude`)에 설치된 스킬들이 스킬 목록에서 **2번씩 중복 노출**된다.

## 2. 근본 원인 (조사 완료)

| # | 원인 | 규모 | 위험도 | 정본 판정 |
|---|------|------|--------|----------|
| 1 | `commands/*.md`(슬래시 커맨드) + `skills/*/`(스킬) **양쪽 등록** | 32개 | 🟡 의도된 공존 | **건드리지 않음** |
| 2 | `~/.claude/commands/.claude/commands/` **중첩 그림자 사본** | 42개 + lib/hooks | 🔴 설치 버그 | **삭제 대상** |

- 원인 2 검증: 중첩본은 원본과 내용 100% 동일, 원본의 부분집합 → **안전 삭제 가능**
- 원인 1은 Claude Code가 커맨드/스킬을 둘 다 지원하는 정상 구조 → **범위 제외**

## 3. 목표 / 비목표

**목표**
- 원인 2(중첩 사본) 완전 제거로 그림자 중복 해소
- 삭제 전후 정상 스킬 개수 불변 검증 (회귀 방지)

**비목표**
- 원인 1(32개 양쪽 등록) 정리 — 슬래시 커맨드 손실 위험으로 보류

## 4. 구현 방식 (TDD)

설치/삭제는 파괴적이므로 **TDD로 가드 테스트 선작성** 후 실행.

### RED — 실패하는 테스트
1. `중첩 디렉토리 ~/.claude/commands/.claude 가 존재하지 않아야 한다` → 현재 존재하므로 FAIL
2. `중첩 제거 후에도 원본 정상 스킬 .sh 개수가 동일해야 한다`

### GREEN — 최소 구현
- 백업 후 `~/.claude/commands/.claude` 디렉토리 제거

### REFACTOR
- `install.sh`에서 중첩을 만드는 원인 라인 점검 (재발 방지)

## 5. 검증 기준 (Acceptance)
- [ ] `~/.claude/commands/.claude` 부재
- [ ] 원본 `~/.claude/commands/*.sh` 개수 변화 없음
- [ ] `~/.claude/skills/` 개수 변화 없음
- [ ] 삭제 전 백업 존재

## 6. 롤백 계획
- 삭제 전 `~/.claude/commands/.claude` → tar 백업
- 문제 시 백업에서 복원
