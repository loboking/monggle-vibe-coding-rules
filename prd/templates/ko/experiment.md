# Experiment PRD Template

> 실험적 기능을 시도할 때 사용하는 템플릿입니다.

---

## 🔵 Front Matter

```yaml
---
experiment_id: ""             # 실험 ID (선택)
experiment_name: ""           # 실험 이름 (예: AI 기반 코드 추천)
experiment_type: "experiment" # 타입: experiment (고정)
hypothesis: ""               # 가설 (예: AI 기반 코드 추천은 개발자 생산성을 20% 향상시킬 것이다)
duration: ""                 # 실험 기간 (선택)
success_metrics: []          # 성공 지표 (선택)
assignee: ""                   # 담당자 (선택)
estimated_hours: ""            # 예상 작업 시간 (선택)
---
```

**형식**: 만약 [조건]이라면, [결과]일 것이다.

**예시:**
```
만약 "코드 작성 시 AI 기반 추천을 제공"하면,
"개발자의 코드 작성 속도가 20% 향상될 것이다"입니다.
```

## 사용 가이드

1. 이 템플릿을 `prd/` 폴더에 복사하세요.
2. Front Matter의 필수 필드를 채우세요.
3. 필수 섹션(1-4)을 작성하세요.
4. 선택 섹션(5-7)은 필요에 따라 작성하세요.

```yaml
success_metrics:
  - "코드 작성 속도: 라인/시간"
  - "코드 품질: 버그율"
  - "개발자 만족도"
assignee: "research-team"
estimated_hours: "40"
---

# AI 기반 코드 추천 실험

## Hypothesis

만약 "코드 작성 시 AI 기반 추천을 제공"하면,
"개발자의 코드 작성 속도가 20% 향상될 것이다"입니다.

## Test Plan

### 실험 그룹
- **대상**: 개발팀 10명
- **기간**: 2주간
- **대조 그룹**: AI 추천 없이 개발하는 그룹 (5명)

### 실험 설계
- 실험 그룹은 IDE에 AI 추천 기능이 활성화됨
- 대조 그룹은 기존 IDE 사용

#### 데이터 수집 방법
- 코드 작성 시간 측정
- 코드 리뷰 피드백
- 설문조사

## Success Criteria

- [ ] 코드 작성 속도 20% 향상 (실험 그룹 vs 대조 그룹 비교)
- [ ] 버그율 대조 그룹과 동등하거나 낮음
- [ ] 개발자 만족도 4.0/5.0 이상 (실험 그룹)

## Rollout Criteria

- [ ] 성공 기준 3개 모두 충족
- [ ] 기술적으로 안정적임
- [ ] 운영 비용 증가가 10% 이내
```
