# 功能 PRD 模板

> 用于开发新功能的模板。

---

## Front Matter

```yaml
---
feature_name: ""               # 功能名称 (例如: 用户认证)
feature_type: "feature"        # 类型: feature (固定)
priority: ""                  # 优先级: high, medium, low
points: []                    # 相关故事点 (可选)
dependencies: []              # 依赖任务 ID (可选)
assignee: ""                   # 负责人 (可选)
estimated_hours: ""            # 预计工作小时 (可选)
tags: []                      # 标签 (可选)
---
```

---

## 必需章节

### 1. 目标 (Goal)

描述要解决的问题和要实现的目标。

**示例:**
```
使用户能够通过电子邮件和社交登录安全地创建账户，
并使用基于 JWT 令牌的身份验证来使用服务。
```

### 2. 需求 (Requirements)

列出功能性和非功能性需求。

#### 功能性需求
- [需求 1]
- [需求 2]
- [需求 3]

#### 非功能性需求
- 性能: (例如: 登录响应时间 < 200ms)
- 安全性: (例如: 密码必须哈希)
- 兼容性: (例如: 支持 Chrome、Firefox、Safari)

### 3. 技术栈 (Tech Stack)

指定要使用的技术栈。

**框架/库:**
- (例如: Python 3.11, FastAPI, PostgreSQL)

**核心依赖:**
- (例如: pyjwt, bcrypt, sqlalchemy)

### 4. 边缘情况 (Edge Cases)

描述预期的异常和处理方法。

- **边缘情况 1**: (例如: 重复电子邮件注册)
  - **处理**: (例如: 返回"电子邮件已存在"消息)

- **边缘情况 2**: (例如: 网络错误)
  - **处理**: (例如: 重试机制，最多 3 次尝试)

### 5. 测试 (Testing)

描述测试策略。

#### 单元测试
- [测试项目 1]
- [测试项目 2]

#### 集成测试
- [测试场景 1]
- [测试场景 2]

#### 端到端测试
- [用户流程 1]
- [用户流程 2]

---

## 可选章节

### 6. 实施计划 (Implementation Plan)

描述分步实施计划。

- **阶段 1**: [步骤 1]
- **阶段 2**: [步骤 2]
- **阶段 3**: [步骤 3]

### 7. 回滚计划 (Rollback Plan)

描述如果出现问题时的回滚策略。

- (例如: 保持现有会话方法，新方法作为可选项)

### 8. 成功标准 (Success Criteria)

指定判断功能是否成功实现的标准。

- [ ] [标准 1]
- [ ] [标准 2]
- [ ] [标准 3]

---

## 使用指南

1. 将此模板复制到 `prd/` 文件夹。
2. 填写 Front Matter 的必填字段。
3. 编写必需章节 (1-5)。
4. 根据需要编写可选章节 (6-8)。
5. 保存文件并运行 Agent 流水线。

---

## 示例

```yaml
---
feature_name: "用户认证"
feature_type: "feature"
priority: "high"
points: [AUTH-1, AUTH-2]
dependencies: []
assignee: "john"
estimated_hours: "8"
tags: ["authentication", "security"]
---

# 用户认证

## 目标

使用户能够通过电子邮件和社交登录安全地创建账户，
并使用基于 JWT 令牌的身份验证来使用服务。

## 需求

### 功能性需求
- 电子邮件注册
- 社交登录 (Google, GitHub)
- JWT 令牌颁发和续订
- 登出
- 密码重置

### 非功能性需求
- 性能: 登录响应时间 < 200ms
- 安全性: 密码 bcrypt 哈希
- 安全性: JWT 令牌过期 1 小时

## 技术栈

**框架/库:**
- Python 3.11
- FastAPI
- PostgreSQL

**核心依赖:**
- pyjwt
- bcrypt
- sqlalchemy
- python-multipart

## 边缘情况

- **重复电子邮件注册**: 返回"电子邮件已存在"消息
- **社交登录失败**: 错误消息和重试提示

## 测试

### 单元测试
- 电子邮件重复检查
- 密码哈希验证
- JWT 令牌颁发和验证

### 集成测试
- 完整登录流程
- 社交登录回调

### 端到端测试
- 用户注册 → 登录 → 登出场景
```
