# PRD: Brain Always-On Memory System (상시 기억 시스템)

> **Type**: feature
> **Created**: 2026-06-17
> **Priority**: P0 (Brain 시스템의 핵심 정체성)
> **Status**: Draft (기획)

---

## 1. 배경

### 1.1 현재 상태

Brain 시스템은 생체모방 메모리(neuron / synapse / 감정가중치 / 망각곡선)로 설계됐고,
망각 곡선은 에빙하우스 지수감쇠로 최근 개선 완료(judge 승인). 그러나 **"언제 작동하는가"가
극히 제한적**이다.

| 작동 지점 | 현재 | 문제 |
|-----------|------|------|
| 세션 시작 | ✅ SessionStart 훅 | 프로젝트 기억 1회 로드뿐 |
| `/debug`, `/test` | ✅ 자동 회상 | 단 2개 스킬만 |
| `/review`, `/qa`, `/prd` 등 | ❌ 미연결 | 하네스 추적만, 기억 회상 X |
| **일반 대화 (슬래시 없는 메시지)** | ❌ 미연결 | **대부분의 작업이 여기인데 Brain이 전혀 안 닿음** |
| 메시지 단위 저장 | ❌ | 세션 통째 덤프 → "빈 뉴런" 양산 |
| 시냅스 자동 연결 | ❌ 미구현 | 시냅스 0개, 기억 간 연결 없음 |

### 1.2 핵심 문제 정의

> **"Brain은 뇌를 표방하는데, 정작 대화 한 번 한 번에는 작동하지 않는다."**

사람의 뇌는 모든 순간 배경에서 회상하고 기록한다. 현재 Brain은 특정 스킬에서만 깜빡이는
"반쪽짜리 뇌"다. 특히:
- 일반 대화(가장 빈번한 작업)에서 과거 기억을 전혀 못 꺼낸다.
- 세션을 통째로 한 뉴런에 덤프해 알맹이가 없다(검토에서 "빈 conversation 뉴런" 확인됨).
- 기억끼리 연결(시냅스)이 안 돼 "관련 기억"이라는 개념이 작동하지 않는다.

### 1.3 사용자 통찰 (기획 논의에서 도출)

> "Brain은 모든 세션 메시지에 실행이 되어야 하는 거 아니야?"
> "그 메시지 한 번 한 번이 뉴런? 가장 작은 단위 아니야?"

→ **메시지가 뉴런의 자연스러운 최소 단위**이며, **회상(읽기)과 축적(쓰기)은 분리할 수 없는
한 사이클**이라는 설계 원칙 확정.

## 2. 목표 (Goal)

**바이브 코딩의 모든 메시지에서 Brain이 배경으로 회상하고 선별 축적하는 "상시 기억 루프" 구축.**

```
[메시지 입력]
   → UserPromptSubmit 훅: 관련 과거 뉴런 회상 → 컨텍스트에 조용히 주입
[Claude 응답]
   → 회상된 기억을 활용해 답변
[응답 종료]
   → Stop 훅: 이번 턴이 의미있으면 메시지 단위 뉴런으로 저장 + 시냅스 자동 연결
[주기]
   → 안 쓰는 뉴런은 에빙하우스 망각곡선으로 자연 소멸 (기구현)
```

### 2.1 성공 기준 (Acceptance Criteria)

- [ ] 슬래시 없는 일반 대화에서도 관련 과거 기억이 자동 회상되어 응답에 반영된다.
- [ ] 의미있는 메시지가 메시지 단위 뉴런으로 저장된다(세션 통째 덤프 폐지).
- [ ] 잡담("응", "고마워")은 뉴런으로 저장되지 않는다(중요도 선별 작동).
- [ ] 관련 뉴런끼리 시냅스가 자동 생성된다(시냅스 0 → 유의미한 연결).
- [ ] 매 메시지 회상 오버헤드가 체감되지 않는다(< 100ms, 백그라운드).
- [ ] 회상 결과가 시끄럽게 화면을 덮지 않는다(조용한 컨텍스트 주입).
- [ ] 히스토리/로그/파이프라인 기록은 망각과 무관하게 보존된다(기존 유지).

## 3. 설계 (Design)

### 3.1 작동 범위 — 모든 메시지

| 훅 | 시점 | 역할 |
|----|------|------|
| **SessionStart** | 세션 시작 | 프로젝트 핵심 기억 + 핫캐시 로드 (기구현, 유지) |
| **UserPromptSubmit** | 매 메시지 받을 때 | **[신규]** 메시지 내용 기반 관련 뉴런 회상 → `additionalContext` 주입 |
| **Stop** | 매 응답 끝날 때 | **[신규]** 이번 턴 중요도 판정 → 뉴런 저장 + 시냅스 연결 |
| **SessionEnd** | 세션 종료 | 세션 기록 보존 + 24h 주기 망각 청소 (기구현, 유지) |

### 3.2 기억 단위 — 메시지/사실 단위 뉴런

- 기존 "세션 1개 → 뉴런 1개(빈 덤프)" 폐지.
- 새 단위: **의미있는 한 턴(메시지+응답의 핵심) = 뉴런 1개**.
- 뉴런 내용: 제목(요약) + 핵심 사실/결정 + 태그 + 감정가중치(중요도).

### 3.3 중요도 선별 — 3단계 결합 (잡담 폭증 방지)

저장 여부를 다음 순서로 판정:

1. **키워드 신호 (명백)** — `결정했다/채택/버그/수정함/하지마/기억해/중요/주의` 등
   포함 시 즉시 저장 대상. 감정가중치 상향.
2. **행동 신호 (자동)** — 이번 턴에 파일 수정/커밋/스킬 실행 같은 "실제 변화"가
   있었으면 저장 대상. (단순 질문·조회·잡담 제외)
3. **AI 판단 (애매한 것)** — 위 둘에 안 걸리지만 애매한 경우, 응답 종료 시
   "이 턴이 미래에 회상할 가치가 있는가?"를 판정해 결정.

→ "응", "고마워", 단순 확인은 셋 다 통과 못 해 저장 안 됨.

### 3.4 시냅스 자동 연결 (신규 구현)

- 새 뉴런 생성 시, 태그/내용이 겹치는 기존 뉴런과 자동으로 시냅스 생성(`link_to_related`).
- 같은 주제가 반복되면 시냅스 가중치 강화(이미 `brain_strengthen_synapse` 존재).
- 회상 시 시냅스로 연결된 뉴런도 함께 끌어올림("관련 기억").

### 3.5 회상 방식 — 조용한 주입

- UserPromptSubmit 훅이 `hookSpecificOutput.additionalContext`로 회상 결과를
  **Claude 컨텍스트에만 주입**(사용자 화면을 덮지 않음).
- 화면 노출은 SessionStart 핫캐시 등 명시적 지점에서만.

### 3.6 성능

- 회상 1회 ≈ 34ms 실측(뉴런 4개). 1000개여도 jq 선형스캔 ~50ms.
- UserPromptSubmit 타임아웃 30s 내 충분. 실패 시 graceful skip(대화 차단 금지).

## 4. 범위 (Scope)

### 4.1 In Scope (이번 PRD)
- UserPromptSubmit / Stop 훅 추가 및 settings.json 등록
- 메시지 단위 뉴런 저장 (세션 덤프 폐지)
- 3단계 중요도 선별 (키워드 + 행동 + AI)
- 시냅스 자동 연결 (`link_to_related` 구현)
- 회상의 조용한 컨텍스트 주입
- install.sh가 신규 훅을 자동 등록

### 4.2 Out of Scope (차기)
- prediction error / dopamine 학습 메커니즘 (SPEC에만 존재, 별도)
- 간격 반복(spaced repetition) 스케줄러
- cortex 핫캐시 접근빈도 자동 갱신 고도화
- 다중 사용자/팀 공유 기억

### 4.3 보존 (변경 없음)
- 에빙하우스 망각곡선 (완료)
- 히스토리/로그/파이프라인 기록 영구 보존
- 감정가중치(amygdala), 세션 기록(hippocampus)

## 7. 검증 계획

- 일반 대화에서 회상 주입 동작 확인(슬래시 없이).

- 시냅스 자동 생성 후 관련 회상 동작 확인.
- 회상 오버헤드 측정(< 100ms).
- 훅 재진입/타임아웃 안전성.
- review 스킬 검수 → judge 최종 승인.
