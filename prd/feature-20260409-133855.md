# Git 기반 팀 협업 시스템

## 목표

Git 기반 팀 협업을 위한 안전한 동기화 및 충돌 해결 시스템을 구축한다.

## 배경

- 현재: 개인용 Claude Code 스킬 모음
- 문제: 팀 단위 협업을 위한 Git 동기화 연결 부재
- 필요: GitHub, GitLab, Bitbucket 지원 협업 스킬

## 요구사항

### 올바른 협업 흐름

```
┌─────────────┐     pull      ┌─────────────┐
│  내 로컬    │ ◄──────────────► │  원격 main  │
│  (작업중)   │                 │  (최신)    │
└─────────────┘                 └─────────────┘
        │                              ▲
        │                              │
        │    작업 완료 후               │
        │         push                 │
        └──────────────────────────────┘
```

### 문제: 내 작업 vs 원본 변경

```
상황:
  원본 main:     A---B---C (새로운 변경)
  내 작업:        D---E (내 작업)

문제:
  C와 D가 같은 파일을 건드리면 충돌!
```

### 1. Git 저장소 감지
- `.git` 디렉토리로 자동 감지
- 원격 저장소 연결 상태 확인

### 2. 원격 저장소 연결
```bash
/vcs-connect <url>
```
- Git: `git remote add origin <url>`
- GitHub, GitLab, Bitbucket URL 자동 인식

### 3. 동기화 기능
```bash
/update
  ├─ Git 저장소 감지
  ├─ 변경사항 확인
  ├─ 작업 안전 저장 (git stash)
  ├─ 원본 변경 받기 (git pull --rebase)
  ├─ 내 작업 재적용 (git stash pop)
  └─ 충돌 해결 가이드
```

### 4. 팀 모드 활성화
```bash
/mode team
```
- 원격 저장소 연결된 상태에서만 활성화 가능
- 팀원 정보 관리

### 5. 팀원 관리
```bash
/team
  ├─ 멤버 목록
  ├─ 브랜치 담당
  └── 작업 현황
```

## 해결 방법

### 4단계 충돌 해결 프로세스

```

                              │

│  1단계: 작업 안전 저장                                          │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ git stash push -m "작업 중인 변경사항"                  │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  2단계: 원본 변경 받기                                           │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ git pull --rebase origin main                          │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  3단계: 내 작업 재적용                                           │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ git stash pop                                          │   │
│  │ (충돌 발생 시 자동 감지)                                │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  4단계: 충돌 해결 가이드                                          │
│                                                                 │

│  ┌─────────────────────────────────────────────────────────┐   │
│  │ 🔴 CONFLICT: src/auth.ts                                │   │
│  │ 🔴 CONFLICT: src/utils.ts                               │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  해결 옵션:                                                      │

└─────────────────────────────────────────────────────────────────┘
```

### /update 명령어 동작 흐름

```bash
/update
```

**동작 순서:**

1. **Git 저장소 감지** → .git 디렉토리 확인
2. **변경사항 확인** → 작업 중인 파일 목록 표시
3. **안전 저장 확인** → 커밋되지 않은 변경사항 감지
4. **원본 변경 확인** → `git fetch`로 변경사항 미리 확인
5. **사용자 확인** → 진행 여부 묻기
6. **동기화 실행** → git stash → git pull --rebase → git stash pop
7. **충돌 처리** → 발생 시 자동 rollback + 해결 가이드 제공

### /push-safe 명령어 동작 흐름

```bash
/push-safe
```

**동작 순서:**

1. **원본 상태 확인** → `git fetch`로 비교
2. **뒤처짐 감지** → 로컬이 원본보다 뒤처져 있는지 확인
3. **자동 update** → `/update` 자동 실행
4. **충돌 없으면 push** → 안전하게 원격에 전송
5. **PR 생성 (Team 모드)** → GitHub/GitLab/Bitbucket PR 자동 생성

## Solo vs Team 모드 차이

| 항목 | Solo 모드 | Team 모드 |
|------|-----------|-----------|
| **VCS 연결** | 선택사항 | 필수 |
| **/update 동작** | 로컬 브랜치 기준 | 원격 main 기준 |
| **push 전 확인** | 없음 | PR 생성 권장 |
| **충돌 해결** | 사용자 직접 | 팀원 공유 가이드 |
| **커밋 메시지** | 자유 형식 | 구조화된 형식 |
| **코드 리뷰** | 선택사항 | 권장사항 |

## 자동화 스크립트 동작

### /update 스크립트 상세

```bash
#!/bin/bash
# .claude/commands/update.sh

# Git 저장소 확인
if [ ! -d ".git" ]; then
    echo "❌ Git 저장소가 아닙니다."
    exit 1
fi

# 변경사항 확인
if has_uncommitted_changes; then
    echo "⚠️ 커밋되지 않은 변경사항이 있습니다."
    echo "저장하고 진행하시겠습니까? (Y/n)"
    read -r response
    if [[ "$response" =~ ^[Yy]$ ]]; then
        git stash push -m "auto-stash before update"
    fi
fi

# 원본 변경 확인
echo "📡 원본 변경사항 확인 중..."
git fetch origin

if is_behind_origin; then
    echo "📥 원본에 새로운 변경사항이 있습니다."
    echo "진행하시겠습니까? (Y/n)"
    read -r response
    if [[ "$response" =~ ^[Yy]$ ]]; then
        # 충돌 발생 시 대비 현재 상태 백업
        git stash push -m "backup-before-update"

        if ! git pull --rebase origin main; then
            echo "❌ 충돌이 발생했습니다. 자동 rollback 합니다."
            git rebase --abort
            git stash pop
            show_conflict_analysis
            show_resolution_options
        else
            echo "✅ 동기화 완료"
            git stash drop
        fi
    fi
else
    echo "✅ 이미 최신 상태입니다."
fi
```

### /push-safe 스크립트 상세

```bash
#!/bin/bash
# .claude/commands/push-safe.sh

# Git 저장소 확인
if [ ! -d ".git" ]; then
    echo "❌ Git 저장소가 아닙니다."
    exit 1
fi

# 원본 상태 확인
git fetch origin

if is_behind_origin; then
    echo "⚠️ 로컬이 원본보다 뒤처져 있습니다."
    echo "먼저 /update를 실행하세요."
    exit 1
fi

if is_ahead_origin; then
    echo "📤 로컬에 ${COMMITS_AHEAD}개의 커밋이 있습니다."

    # Team 모드 확인
    if is_team_mode; then
        detect_git_host  # github, gitlab, bitbucket
        echo "🔄 Team 모드: PR를 생성하시겠습니까? (Y/n)"
        read -r response
        if [[ "$response" =~ ^[Yy]$ ]]; then
            create_pull_request  # 호스트별 API 호출
        else
            git push origin $(current_branch)
        fi
    else
        git push origin $(current_branch)
    fi
else
    echo "✅ 전송할 커밋이 없습니다."
fi
```

## API 명세

### `/update [options]`
```
원격 저장소의 변경사항을 동기화합니다.

Options:
  --dry-run        실행 계획만 표시
  --auto           사용자 확인 없이 자동 실행
```

### `/push-safe [options]`
```
안전하게 원격 저장소에 전송합니다.

Options:
  --no-pr           PR 생성 건너뛰기
  --branch <name>  특정 브랜치에 전송
```
