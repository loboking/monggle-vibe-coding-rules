# Feature PRD Template

> 새로운 기능을 개발할 때 사용하는 템플릿입니다.

---

## 🔵 Front Matter

```yaml
---
feature_name: ""               # 기능 이름 (예: 사용자 인증 기능)
feature_type: "feature"        # 타입: feature (고정)
priority: ""                  # 우선순위: high, medium, low
points: []                    # 연관된 기술 스토리 포인트 (선택)
dependencies: []              # 의존하는 작업 ID (선택)
assignee: ""                   # 담당자 (선택)
estimated_hours: ""            # 예상 작업 시간 (선택)
tags: []                      # 태그 (선택)
---
```

```yaml
# 사용자 인증 기능

## Goal

사용자가 이메일과 소셜 로그인을 통해 안전하게 계정을 생성하고,
JWT 토큰 기반으로 인증된 상태에서 서비스를 이용할 수 있게 합니다.

## Requirements

### 기능적 요구사항
- 이메일 가입 기능
- 소셜 로그인 (Google, GitHub)
- JWT 토큰 발급 및 갱신
- 로그아웃 기능
- 비밀번호 재설정

### 비기능적 요구사항
- 성능: 로그인 응답 시간 < 200ms
- 보안: 비밀번호 bcrypt 해싱
- 보안: JWT 토큰 만료 1시간

## Tech Stack

**프레임워크/라이브러리:**
- Python 3.11
- FastAPI
- PostgreSQL

**핵심 의존성:**
- pyjwt
- bcrypt
- sqlalchemy
- python-multipart

## Edge Cases

- **중복 이메일 가입 시**: "이미 존재하는 이메일입니다" 메시지 반환
- **소셜 로그인 실패 시**: 에러 메시지와 함께 재시도 유도

## Testing

### 단위 테스트
- 이메일 중복 체크
- 비밀번호 해싱 검증
- JWT 토큰 발급 및 검증

### 통합 테스트
- 전체 로그인 플로우
- 소셜 로그인 콜백

### E2E 테스트
- 사용자 가입 → 로그인 → 로그아웃 시나리오
```
