# team (AI 팀)

사람 여러 명이 같이 개발하는 설정은 이 스킬이 아니라 `mode` 다.

## 언제 팀으로 가나
- 가: 파일 여러 개 + 설계 판단이 필요, 또는 사용자가 팀을 지목
- 안 감: 한두 파일 수정 → `fix`, 동작 확인 → `qa`

## 맡기는 법
1. 팀원 목록 확인: `ls ~/.claude/agents/team_*.md` (Claude Code 전용 기능이다. 다른 도구에서는 `~/.claude/agents-team/<팀>/<이름>/persona.md` 를 읽고 그 역할로 직접 일한다)
2. 팀장 `team_dohyeon` 서브에이전트에게 넘긴다. 넘길 때 작업지시서 5줄을 붙인다:
   `목표(한 문장)` / `관련 파일(파일:라인)` / `관련 코드(핵심 심볼)` / `주의(정해진 것)` / `하지 말 것`
3. 특정 역할만 필요하면 그 팀원에게 바로 넘긴다(예: 리뷰만 → `team_serin`, diff 만 준다).
4. 결과를 사용자에게 보고한다. 커밋·푸시·배포는 팀원이 하지 않는다.

## 채용·성장
`references/team-builder.md` 절차를 따른다(팀원 기억은 보존하고 UPGRADE).
