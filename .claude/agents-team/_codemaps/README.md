# 코드맵 (_codemaps)

> 프로젝트당 1장. 팀장이 Task Package 좌표(파일:라인·심볼)를 꺼내는 공용 지도다.
> 이게 있으면 팀원이 프로젝트를 재스캔할 필요가 없다.

- **파일명:** `<프로젝트명>.md` — 작업 디렉토리 베이스명 소문자 (등록 파일의 프로젝트명 규칙과 동일. 예: `TopDrawer` → `topdrawer.md`)
- **형식:** 전부 `파일:라인 — 무엇` 한 줄씩. 설명 최소.
- **갱신:** 구현·수정으로 좌표가 바뀐 팀원(태오·준)이 잠들기 전에 손으로 갱신한다. 자동 생성 파이프라인 만들지 않는다.
- **동기화 안 함:** 코드맵은 memory처럼 머신별 산출물이다. repo로 커밋하지 않는다 (이 README만 repo가 정본).

## 템플릿

```markdown
# <프로젝트명> 코드맵

## 핵심 파일·심볼
- src/store.ts:120 — appendEvent() (모든 쓰기의 단일 진입점)
- src/ui/App.tsx:45 — 뷰 모드 분기 (list/grid)

## API 라우트
- server/routes.ts:30 — POST /api/sync

## 불변식 (건드리면 안 되는 것)
- 파일 락: withLock() 밖에서 events.json 쓰기 금지
```
