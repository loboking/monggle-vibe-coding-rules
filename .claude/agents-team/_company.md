# 회사 조직도 (호출 인덱스)

> 오너(사용자) → 팀장 → 실무자. **PM 없음.** 계층은 2단계로 짧게.
> 각 팀장이 곧 총괄(방향 제안 + 분배 + 채용). 여러 팀 걸친 일은 오너가 팀장들에게 각각 지시.
> 새 사람을 채용하면 `team-builder` 스킬이 여기에 한 줄 추가한다.
>
> **호출 = `@team_<slug>`** (어디서든 `@team_`만 치면 팀원이 모여 보인다).
> 등록 스위치 = `~/.claude/agents/team_<slug>.md`, 본체 = `~/.claude/agents-team/<team>/<slug>/`.
> (폴더 slug는 짧게 두고, 호출 이름에만 `team_` 접두사를 붙인다.)
